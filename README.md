# The Meeting That Should Have Been an Email

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9)

A make.fun entry for [The Meeting That Should Have Been an Email](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9).

`main.py` (Python 3.13, deterministic, no network) writes a single line —
at most 200 characters, one joke about a meeting that should have been
an email — to `/output/entry.txt`. No input, no dependencies, stdlib only.

## Run

```sh
python3 main.py
```

## Entry

> The meeting's only action item was to email a summary of the meeting — an email, but with snacks and a calendar invite.
